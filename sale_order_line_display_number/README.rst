This module allows to configure the number of sale order lines to be
shown.

**Table of contents**

.. contents::
   :local:

Configuration
=============

To configure this module, you need to:

-  Go to Settings > Technical > System Parameters >
   sale_order_line_display_number.number and introduce the number of
   sale order lines to be shown in the field "Value".

Usage
=====

To use this module, you need to:

1. Go to Sales app and create a sale order.
2. The number of sale order lines displayed is limited to the limit set
   in the technical parameters.
