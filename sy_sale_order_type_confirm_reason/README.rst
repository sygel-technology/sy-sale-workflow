This module allows configuring whether a confirmation reason is required
for each sale order type.

By default, confirmation reasons are disabled for all sale order types.
After installing this module, the confirmation reason wizard will only
be displayed for sale order types where **Require Confirmation Reason**
is enabled.

Usage
=====

To use this module, you need to:

1. Go to **Sales > Configuration > Sales Orders > Sales Order Types**.
2. Select a sales order type.
3. Enable **Require Confirmation Reason** if sale orders of this type
   must require a confirmation reason.
4. Make sure the confirmation reason requirement is also enabled for the
   corresponding company.
5. To confirm a single quotation:

   - Create a quotation using the configured sales order type.
   - Click **Confirm**.
   - If a confirmation reason is required, select a reason in the wizard
     and confirm the sale order.

6. To confirm multiple quotations:

   - Select the quotations from the list view.
   - Select **Action > Confirm Orders**.
   - If at least one quotation requires a confirmation reason, the
     wizard will open.
   - Select a reason and click **Confirm** to confirm the selected
     quotations.

If **Require Confirmation Reason** is disabled for the sales order type,
the quotation can be confirmed without a reason, provided no other
selected quotation requires one.

When confirming multiple quotations, the selected confirmation reason is
applied to all selected quotations.
