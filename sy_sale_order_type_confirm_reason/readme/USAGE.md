To use this module, you need to:

1. Go to **Sales > Configuration > Sales Orders > Sales Order Types**.
2. Select a sales order type.
3. Enable **Require Confirmation Reason** if sale orders of this type must require a confirmation reason.
4. Create a quotation using this sales order type and click **Confirm**.
5. If **Require Confirmation Reason** is enabled, select a confirmation reason in the wizard and confirm the sale order.

If **Require Confirmation Reason** is disabled, the sale order is confirmed directly without displaying the confirmation reason wizard.
