Usage
=====

To use this module, you need to:

1. Go to **Sales > Configuration > Sales Orders > Confirmation
   Reasons**.
2. Create the required confirmation reasons.
3. For each reason, configure whether additional information is allowed:

   - Enable **Allow Manual Text** to allow users to enter additional
     information.
   - Enable **Manual Text Required** to make this additional information
     mandatory.

4. Create a quotation and click **Confirm**.
5. Select a confirmation reason in the wizard.
6. If the selected reason allows manual text, enter the additional
   information if needed.
7. Click **Confirm** to confirm the sale order.
