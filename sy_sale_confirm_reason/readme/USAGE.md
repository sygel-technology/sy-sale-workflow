To use this module, you need to:

1. Go to **Sales > Configuration > Sales Orders > Confirmation Reasons**.
2. Create the required confirmation reasons and assign them to the corresponding company.
3. For each reason, configure whether additional information is allowed:
   - Enable **Allow Manual Text** to allow users to enter additional information.
   - Enable **Manual Text Required** to make this additional information mandatory.
4. Go to **Settings > Sales** and enable the confirmation reason requirement for the corresponding company.
5. To confirm a single quotation:
   - Open a quotation and click **Confirm**.
   - Select a confirmation reason in the wizard.
   - If the selected reason allows manual text, enter the additional information if needed.
   - Click **Confirm** to confirm the sale order.
6. To confirm multiple quotations:
   - Go to the quotations list view and select the quotations to confirm.
   - Select **Action > Confirm Orders**.
   - Select a confirmation reason and enter additional information if needed.
   - Click **Confirm** to confirm all selected quotations.

The same confirmation reason is applied to all selected quotations. The selected reason must belong to the company of the quotations.
