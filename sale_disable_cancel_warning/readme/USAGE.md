To use this module:

**With Disable Cancel Warning enabled:**

1. Create a sales order and confirm it.
2. Cancel the sales order.
3. Verify that the sales order is cancelled directly without displaying the cancellation wizard.

**With Disable Cancel Warning disabled:**

1. Create a sales order and confirm it.
2. Cancel the sales order.
3. Verify that the cancellation wizard is displayed, allowing the customer to be notified of the cancellation by email.
