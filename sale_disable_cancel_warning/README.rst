This module allows to disable the sales order cancellation wizard, which
is displayed when cancelling a sales order and allows the customer to be
notified of the cancellation by email.

Installation
============

To install this module, you need to:

- Only install

Configuration
=============

To configure this module:

- Go to *Sales > Configuration > Settings*.
- In the *Quotations & Orders* section, enable **Disable Cancel
  Warning** to cancel sales orders directly without displaying the
  cancellation confirmation wizard.
- Disable the option to keep the standard cancellation confirmation
  wizard.

Usage
=====

To use this module:

**With Disable Cancel Warning enabled:**

1. Create a sales order and confirm it.
2. Cancel the sales order.
3. Verify that the sales order is cancelled directly without displaying
   the cancellation wizard.

**With Disable Cancel Warning disabled:**

1. Create a sales order and confirm it.
2. Cancel the sales order.
3. Verify that the cancellation wizard is displayed, allowing the
   customer to be notified of the cancellation by email.
