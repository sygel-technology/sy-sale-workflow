This module creates a new permission group that allows you to go from
sales to stock picking and see the 'Forecasted Quantity' and the
'Quantity on Hand' of the stock of the products from the tree view.

Configuration
=============

To configure this module:

1. Go to **Settings > Users & Companies > Users**.
2. Select the user who should have read access to stock information from
   Sales.
3. Add the user to the **Allows you to view the Delivery button from the
   sale and see the stock quantity** group.

This group allows users to:

- View the **Delivery** button on sales orders.
- View the **On Hand Quantity** and **Forecasted Quantity** fields in
  the product stock view.

Please note that this module does not grant permissions to create, edit,
or delete stock pickings. The appropriate Inventory permissions must be
assigned separately for these operations.

Usage
=====

To use this module:

1. Log in with a user who belongs to the **Allows you to view the
   Delivery button from the sale and see the stock quantity** group.
2. Go to **Sales > Orders > Quotations** and create a new quotation.
3. Add a storable product and click **Search More...** in the product
   selector.
4. Verify that the **On Hand Quantity** and **Forecasted Quantity** of
   the products are visible.
5. Confirm the quotation.
6. Verify that the **Delivery** button is visible on the sales order.
7. Click the **Delivery** button and verify that you can access the
   related stock picking.
