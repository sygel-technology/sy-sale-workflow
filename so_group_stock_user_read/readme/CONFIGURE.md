To configure this module:

1. Go to **Settings > Users & Companies > Users**.
2. Select the user who should have read access to stock information from Sales.
3. Add the user to the **Allows you to view the Delivery button from the sale and see the stock quantity** group.

This group allows users to:

* View the **Delivery** button on sales orders.
* View the **On Hand Quantity** and **Forecasted Quantity** fields in the product stock view.

Please note that this module does not grant permissions to create, edit, or delete stock pickings. The appropriate Inventory permissions must be assigned separately for these operations.
