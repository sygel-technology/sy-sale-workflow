To use this module:

1. Go to **Sales > Orders > Quotations** and create a new quotation.
2. Add a product with a configured cost.
3. Set a sales price that results in a positive margin and verify that the order line is displayed normally.
4. Change the sales price so that the line has a negative margin and verify that the order line is highlighted in red.
5. Set the sales price so that the margin is exactly zero and verify that the order line is also highlighted in red.
6. Change the sales price again so that the margin becomes positive and verify that the red highlighting disappears.
