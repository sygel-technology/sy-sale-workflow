Usage
=====

To use this module:

1. Go to **Sales > Orders > Quotations** and create or open a quotation.
2. Select a payment mode that requires a direct debit mandate.
3. The **Direct Debit Mandate** field will be displayed below the
   **Payment Mode** field.
4. Select the corresponding mandate.

The **Direct Debit Mandate** field is only displayed when the selected
payment mode requires a mandate.
