This module allows to set domains in sale order types that need to be
met when a sale order is confirmed.

**Table of contents**

.. contents::
   :local:

Configuration
=============

To configure this module, you need to:

1. Go to Sales > Configuration > Requirement Rules.
2. Create a new rule and set a name, a domain and an error message,
   which is shown in case the condition is not met.
3. Go to a Sale Order Type and select which rules have to be checked
   before confirming a sale order of that type.

Usage
=====

To use this module, you need to:

1. Create a Sale Order
2. Select a sale order type with requirement rules
3. Edit the order fields to do not pass the rules
4. Confirm the order with a user that can't skip the rules, a error
   message will be displayed
